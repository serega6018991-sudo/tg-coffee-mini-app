# Bot Messages

This document keeps bot-dialog copy and states out of the first-release interface. These messages should be used in Telegram bot notifications, not as a visible profile block inside the app.

## Первый вход

Purpose: request the phone number through Telegram without manual typing.

Message: `Поделись номером, чтобы бариста мог связаться по заказу.`

## Нужна оплата

Purpose: explain that the order was not sent to the barista because payment is missing or the coffee balance is too low.

Message: `Не хватает 42 грн. Оплати картой или пополни баланс.`

## Заказ готов

Purpose: give the pickup code and status.

Message: `Готово. Назови код 4831 у стойки.`

## Подарок

Purpose: tell the recipient that a gift link can be opened and activated.

Message: `Анна отправила тебе кофе. Открой подарок.`
